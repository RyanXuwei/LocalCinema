# 安全邊界

LocalCinema 是可信任本機／區網的私人影音工具，並非面向公網的多租戶服務。

## LAN admission

後台產生帶 access 參數的 LAN 入口連結，首次成功後轉成 HttpOnly／SameSite=Lax Cookie（支援掃碼後頂層導覽）；loopback 仍可直接進入。Host／Origin 檢查、前端請求 token 與防嵌入標頭提供額外限制。CORS 或 UI 隱藏本身不等於授權。

不要把入口連結、cookie、設定或資料庫提交 Git／貼到公開問題；也不要自行開放路由器連接埠。HTTP 不加密傳輸，請用可信任網路；密碼 hash 不會令 HTTP 密碼傳輸變成加密。

## 隱藏頻道

PBKDF2-HMAC-SHA256（每密碼隨機 salt、200000 iterations）保存驗證值，設定可改密碼但不可回讀。正確密碼解鎖相符頻道，伺服器以不透明 cookie token 保存 session，授權含 group revision，最多 8 小時。每來源位址一分鐘最多 5 次失敗。

隱藏頻道過濾群組、items、groupCategories／groupTags 與代表圖；媒體、封面、preview prepare、推薦與影片操作也受後端檢查。更改隱藏設定或密碼撤銷既有 revision。後台重啟不延續 session。

相同影片若也屬公開群組可由公開群組存取；此功能不隔離硬碟檔案、不防電腦本機使用者，亦不能撤回已下載內容。既有 LAN 存取碼與頻道密碼是不同控制。

## 隱蔽與 Hide

毛玻璃只改畫面；Hide 會暫停／禁音／隱藏內容。兩者不是加密或權限措施。系統播放器不使用網頁遮罩，因此開啟人工檢查成品時會另行提醒。

## 問題回報

請提供版本、重現步驟、合成片單及錯誤摘要。移除影片名稱、路徑、存取連結、密碼與設定資料。尚未設定專用漏洞回報管道，請勿在公開 issue 張貼敏感細節。

## 快取清理

清理僅針對已驗證存在另一份完整保存副本的程式快取，逐檔核對 SHA256 並排除待辦引用，不依檔名或年齡直接刪除影片。空間不足會停止轉檔，不自動刪除原始影片或清空回收筒。搬移路徑、快取統計與清理入口僅在本機後台提供，不透過媒體 API 暴露。
